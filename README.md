# Urban Style – Portal web y carrito de compras

MVP Front-End para la marca Urban Style: inicio de sesión por URL, catálogo, cálculo de subtotal, descuento, IVA y total en euros, Oferta Relámpago, reseñas persistentes y renderizado seguro.

## Funcionalidades
- Sesión y entorno: usuario, rol, idioma, conexión, ID seguro y fecha en español.
- Sanitización de email, ID de cliente a 6 dígitos y valores por defecto.
- Catálogo, parseo de precios, descuento, IVA 21% y formato en euros.
- Oferta Relámpago de 15 s con control de ejecuciones múltiples.
- Reseñas con `localStorage`, manejo de errores y protección XSS con `textContent`.

## Tecnologías
HTML5, CSS3 y JavaScript (ES6+) con `'use strict'`.

## Estructura
`index.html`, `styles.css`, `app.js`

## Ejecución
Abre `index.html` en el navegador o usa Live Server.
